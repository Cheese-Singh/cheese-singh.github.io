Projects
Gwen Flagship 90% complete

Fully local, privacy-first voice AI assistant for Apple Silicon (MacBook, iPhone, Apple Watch). Voice input → MLX-Whisper transcription → tiered LLM inference with tool-calling → MLX-audio TTS output, with speaker verification (ECAPA-TDNN) and full-duplex, barge-in-capable conversation via WebRTC echo cancellation. A 4-tier model router balances on-device and cloud inference for latency, cost, and quality, and a novel query-routing layer grounds responses to reduce hallucination. Multimodal I/O extends to local image generation and image/PDF/DOCX understanding. Zero cloud dependency for the core loop — cloud is opt-in fallback only.

MLX Swift MLX-Whisper MLX-audio SpeechBrain Tool-calling SwiftUI Apple Silicon
Fungal Keratitis Diagnosis PGI-MER In Progress

Computer vision system for screening fungal keratitis from In Vivo Confocal Microscopy images and patient risk factors, built with a 3-person team in partnership with PGI-MER. Led system architecture and the LLM-based layer that turns model outputs into clinician-readable summaries. Stacked ensemble classifier reaching ~99–100% accuracy on held-out data.
