Projects
Gwen Flagship

Fully local, privacy-first voice AI assistant for Apple Silicon (MacBook, iPhone, Apple Watch). Speaker-verified, multi-tier, multimodal — a 15-stage build from tensor fundamentals to a full voice-driven system agent. 4-tier model routing (Qwen2.5-1.5B → Qwen3.5-9B → Gemma4b:cloud → Kimi-K2.7-Code:cloud via Ollama Cloud) with automatic cloud-to-local fallback. Speaker verification and voice authentication via an ECAPA-TDNN model, plus WebRTC AEC3 echo cancellation for full-duplex, barge-in-capable conversation. Multimodal I/O includes local image generation (4-bit ZImageTurbo) and image/PDF/DOCX understanding and generation, with a novel query-routing system for grounding responses and reducing hallucination.

MLX / MLX-LM MLX-VLM MLX-Whisper MLX-audio (Kokoro-82M) SpeechBrain Ollama Cloud mflux SwiftUI Apple Silicon
Automated Fungal Keratitis Diagnosis Research · PGI-MER

End-to-end computer vision system for screening fungal keratitis, a severe corneal infection, using In Vivo Confocal Microscopy images and patient risk-factor history - built with a 3-person team for PGI-MER. Led system architecture and planning, and built the LLM-based summary layer translating model outputs and risk factors into clinician-readable diagnostic summaries. Stacked ensemble classifier (Mixture of Experts + Snapshot Ensemble of Random Forests) benchmarked across seven image-processing pipelines, reaching ~99–100% accuracy on held-out test data.

Python FastAPI Scikit-learn OpenCV React Ollama
