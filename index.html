Gwen — Local Personal AI Assistant
Flagship · Apr 2026 – Present v1.1 · Live

A fully local, privacy-first, agentic voice assistant for Apple Silicon, with a native SwiftUI interface and a Python/FastAPI backend. It grew out of the MLX exploration series and was built independently across 15 progressive stages.

  • Four-tier model routing from on-device to cloud with automatic fallback, plus a query-routing layer built to ground responses and reduce hallucination.
  • Full-duplex voice: speaker verification (ECAPA-TDNN), acoustic echo cancellation (WebRTC AEC3), sentence-level TTS, interruption handling, and voice/text mode switching.
  • Memory and tools: persistent state, session history, semantic memory and retrieval, tool-calling, macOS system control, and multimodal I/O (image, PDF, Word).

LLM Cascade — Minimum Sufficient Inference
Research · 2026 Phase III complete

How much LLM inference is actually needed for reliable task completion? This project tests whether a cascade can stop once enough inference has been done, instead of always calling the strongest model. The ladder is gpt-oss-20b → gemma4 → nemotron-3-super → nemotron-3-ultra, and stronger layers receive the failed candidate and objective execution feedback.

  • Phase I: sandboxed harness over 100 code problems with deterministic tests. L1 alone reached 90%; execution-gated escalation reached 100% while escalating only 8% of problems (all resolved at L2), with mean tokens rising from 693 to 808 per query.
  • Phase II: contextual sequential evaluation across coding, mathematics, and finance, establishing oracle labels for the minimum sufficient layer per problem.
  • Phase III: a logistic-regression router trained on cheap response features (confidence, answer similarity, length, numeric density, reasoning structure, final-answer presence) on TAT-QA, with no LLM judge at inference. On 50 held-out questions it reached about 96% routing accuracy and cut latency by about 76% versus always using the strongest model.
  • Finding: self-reported confidence correlated negatively with correctness (−0.73), so it is a poor reliability signal.

Automated Fungal Keratitis Screening
Research · Jul 2026 Prototype

A computer vision system for screening fungal keratitis from In Vivo Confocal Microscopy images and patient risk factors, built by a 3-person team after a PGI-MER physician raised a clinical need to faculty. Seven image-processing pipelines were benchmarked; Model 7 powers the production pipeline, with a stacked ensemble for classification. I led system architecture and built the LLM-based layer that turns model outputs and risk factors into clinician-readable summaries.

The prototype was developed and evaluated independently by our team. There is no formal agreement with PGI-MER, and clinical adoption or deployment there has not taken place.
